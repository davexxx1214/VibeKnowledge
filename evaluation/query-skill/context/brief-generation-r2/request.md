# Independent author request

The author was started with no history fork. It received the frozen repository
workspace and the following requested feature areas: graph refresh, installation
of the dependency-graph/query Skills, entity description editing, and MCP setup.
It was asked to produce reusable capabilities, entry points, dependency roles,
relevant frameworks, tests and evidence-backed constraints, not solve a future
coding task. No development/held-out prompts, rubric, prior report, outcome or
token-saving target was supplied. Feature areas were selected for this trial;
this is not a blind benchmark over unknown feature selection.

The full generation contract is archived in authoring-instructions.md. Source
searches/reads used the common observer with phase `generation`. Authoring used
apply_patch for drafts and the supplied publisher for schema/path/range/hash
validation. No source edits, dependency installation, test execution, internet,
MCP, other workspaces, evaluation material or subagents were permitted. The
author recorded source gaps in GENERATION.md and card limitations.

Publisher validation proves paths/ranges/hashes, not semantic correctness. The
subsequent task report grading checks factual use independently. Numeric usage
and observed text are recorded in metrics.json / telemetry.json / observations.jsonl.
The generation cost is for all four features together; it cannot honestly be
assigned to one future task or described as a warm-query saving.
