# Skill precision: targeted development validation

Compare the pre-change and candidate implementations for two authorized changes:
source-backed brief review and exact-symbol dependency context. This is a
development regression/pilot, not a preregistered full-agent efficiency claim.
Do not overwrite earlier A/B artifacts or regenerate their frozen inputs.

1. Save the original taskContext implementation/brief guidance and measure the
   same known VibeKnowledge source snapshot before changes. Query three exact
   methods plus a file-selector control at the same budget/depth. Archive all
   outputs, input hashes and o200k_base counts; count text rather than infer
   billing. Symbols and required dependencies must remain visible, and same-file
   helpers, callers, tests, receiver/type references and ambiguous names need
   regression checks. File mode should retain its existing output.
2. Two fresh independent authors receive identical copies of a small synthetic
   bundle-export feature and only their assigned brief-authoring instructions.
   One uses the original guidance, the other the revised guidance. They write a
   source-backed brief draft with the same existing schema. They do not receive
   a rubric, expected pitfalls, other-arm instructions or previous answers.
   Only the assigned source, instructions and output may be accessed; no tests,
   installs, graph generation, network or subagents by authors.
3. A fresh blind grader receives anonymized drafts and the fixed source/rubric,
   without methods or metrics. Score supported behavior and major false claims;
   do not modify instructions or rerun authors after seeing results.

The synthetic example intentionally exercises the failure classes identified in
review. It is not held out from the developer and cannot establish generalization
or end-to-end task-token savings. A single pair has model/grader variance. Report
ties/regressions, generation/reading cost where measured, and any limitations.
Product tests validate observable traversal contracts, not instruction wording.
